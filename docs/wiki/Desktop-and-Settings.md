# Desktop and settings

The desktop uses dwm; **Super** is normally the Windows or Command key. Open the menu with **Super+Escape** or the Menu button.

## Default keyboard shortcuts

These are the default bindings; your active shortcuts can differ if you customize them. **Super** is usually the Windows or Command key. Optional applications must be installed before their shortcuts can open them.

| Shortcut | Action |
| --- | --- |
| Super+Return | Open terminal |
| Super+Alt+Return | Open alternate terminal |
| Super+Escape | Open Abyss menu |
| Super+` | Toggle scratchpad terminal |
| Super+F1 | Show shortcuts |
| Super+p | Run a command |
| Super+s | Open SSH menu |
| Super+b | Open browser |
| Super+c | Open VS Code |
| Super+v | Open virtual machine manager |
| Super+Shift+l | Lock screen |
| Super+Shift+b | Toggle status bar |
| Super+Shift+c | Close focused window |
| Super+Shift+q | Log out of dwm |
| Super+j / k or Super+Down / Up | Focus next / previous window |
| Super+Shift+j / k or Super+Shift+Down / Up | Move window down / up in the stack |
| Super+h / l | Shrink / grow master area |
| Super+i / d | Add / remove a master window |
| Super+Shift+Return | Make focused window master |
| Super+t / f / m | Select tiled / floating / monocle layout |
| Super+Space | Switch layout |
| Super+Shift+Space | Toggle floating for focused window |
| Super+Left / Right | Switch to previous / next tag |
| Super+Shift+Left / Right | Move window to previous / next tag |
| Super+1–9 | View tag |
| Super+Ctrl+1–9 | Toggle tag in current view |
| Super+Shift+1–9 | Move window to tag |
| Super+Ctrl+Shift+1–9 | Toggle tag on window |
| Super+0 | View all tags |
| Super+Shift+0 | Assign window to all tags |
| Super+Tab | View previous tag set |
| Super+, / . | Focus previous / next monitor |
| Super+Shift+, / . | Move window to previous / next monitor |
| Super+Alt+0 | Toggle gaps |
| Super+Alt+Shift+0 | Reset gaps |
| Super+Alt+= / - | Increase / decrease gaps |
| Print | Save full-screen screenshot |
| Shift+Print | Select and save screenshot area |

Use the keyboard settings in the menu to inspect and configure shortcuts. Available actions and shortcuts may vary with the installed package version.

**Display settings** offer resolution, refresh rate, monitor arrangement and idle blanking. Available modes depend on the graphics driver, monitor and, in a VM, the virtual display. Xorg scaling and mixed-DPI behavior vary between applications.

Use **Menu → Software** or **Install software** to browse Void packages and optional vendor applications. Availability varies by architecture and vendor. Vendor-installed applications may use their own update mechanism.
