# Abyss Linux Wiki

Abyss Linux is a lightweight desktop built on [Void Linux](https://voidlinux.org/) with dwm and other suckless tools. Void supplies the base system and its rolling repositories; Abyss provides desktop configuration and packages through the [Abyss Linux PMR](https://github.com/MrZaKaRiA/AbyssLinuxPMR).

- [Getting started](Getting-Started): downloads, installation and first login
- [Desktop and settings](Desktop-and-Settings): shortcuts, displays and software
- [Updates and troubleshooting](Updates-and-Troubleshooting): XBPS and common problems
- [Releases](https://github.com/MrZaKaRiA/AbyssLinux/releases) · [Report an issue](https://github.com/MrZaKaRiA/AbyssLinux/issues) · [Contributing](https://github.com/MrZaKaRiA/AbyssLinux/blob/main/CONTRIBUTING.md)

Abyss Linux is a community project and is not affiliated with Void Linux or suckless.org.
